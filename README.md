# Weather App

A simple weather app built with Next.js. Search for a city, pick one from the list, or use your current location to see the current weather.

![Screenshot](public/screenshot.png)
**Live demo:** _coming soon_

## Features

- City search with live suggestions as you type
- Current location support (via browser geolocation)
- Current temperature, humidity and wind
- Background that changes with the time of day
- Responsive layout

## Tech stack

- Next.js (App Router) + React
- TypeScript
- SCSS Modules

## Getting started

```bash
npm install
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000).
